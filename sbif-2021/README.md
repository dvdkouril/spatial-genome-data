# Example from sBIF

- Title: *High-resolution single-cell 3D-models of chromatin ensembles during Drosophila embryogenesis*
- DOI: [https://doi.org/10.1038/s41467-020-20490-9](https://doi.org/10.1038/s41467-020-20490-9)
- Code: [https://github.com/qiusun0215/sBIF](https://github.com/qiusun0215/sBIF)
- Organism: Drosophila

Process:
- Cloned the repository
- Compiled according to instructions (`cmake .`, `make`)
- Ran the example: `cd example` and `./drosChr2L.sh`
- Results in 50000 conformations (`dros.0.txt - drox.49999.txt`)
- Randomly selected several structures

Only managed to run the tool a Ubuntu system, had issues on Macos.
